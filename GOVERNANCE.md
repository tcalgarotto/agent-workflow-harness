# Governance

This is a maintainer-led early-stage project. The repository owner maintains the
initial roadmap and reviews public contract changes. Contributors may propose
decisions through issues and pull requests. An implementer must not represent its
own automated output as independent verification.

Changes affecting authorization, isolation, state transitions, or validation
requirements need explicit maintainer review and evidence. Record significant
architecture decisions in docs/decisions. Existing users need migration guidance
before a breaking contract change is accepted.

Repository settings and branch protection are separate controls. This file does
not establish enforcement or claim those settings are already enabled.
